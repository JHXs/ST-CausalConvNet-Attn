1. 为什么 1 层可以？
  当 num_layers = 1 时，你的输入数据 $X$ 直接连接到这唯一的一层 RNN 单元。
   * 信号路径短：输入特征直接“喂”给神经元，模型能直接看到原始数据。
   * 梯度回传容易：在反向传播时，误差只需要穿过时间步（Time
     Steps），不需要穿过额外的纵向网络层。虽然时间步长了也会梯度消失，但至少输入层的权重能直接收到来自输出的反馈。
2. 为什么 2 层（或更多）就不行？
  当 num_layers = 2 时，结构变成了： 输入 -> Layer 1 -> Layer 2 -> 输出。

   * Layer 1 变成了“盲人”：
       * Layer 2 接收的是 Layer 1 的输出，而不是原始数据。
       * 在训练初期，Layer 1 是随机初始化的（也是全零状态开始），它的输出基本上是无意义的噪声。
       * Layer 2 试图从这些噪声中学习，自然学不到东西。
   * 梯度的“双重”衰减：
       * RNN 的梯度不仅要在时间维度（Time Steps）上传导（这本身就很难，容易消失），现在还要在深度维度（Layers）上传导。
       * 误差信号想传回 Layer 1（去更新那个负责提取原始特征的权重），必须先穿过 Layer 2。
       * 在 SimpleRNN 中，激活函数是 tanh，导数小于 1。层数一多，梯度 $\times 0.x \times 0.x \dots$，传到第一层时几乎就等于 0 了。
       * 结果就是：Layer 1 的权重几乎不更新，Layer 2 看着 Layer 1 输出的垃圾束手无策。

3. 为什么 LSTM/GRU 没有这个问题？
  如果换成 LSTM 或 GRU，即使 4 层也能训练。
   * 因为它们内部有 “门控机制” (Gates)，特别是“遗忘门”或“更新门”，允许梯度以接近 1.0 的值无损地流过长距离（Highways），就像高速公路一样。
   * SimpleRNN 没有这种机制，它在每一层、每一步都强制进行非线性压缩，导致信息快速丢失。

  总结
  你遇到的情况完全符合深度学习理论：对于不带门控机制的 Vanilla RNN，通常只能使用 1 层。 一旦加深，必须使用 LSTM、GRU 或残差连接（Residual
  Connections）等技术。
